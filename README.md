## 🔧 What I work on

- **LLM integration:** MCP server (FastMCP) connecting Claude, ChatGPT and Grok to internal systems with role-based access control; RAG on PostgreSQL + pgvector
- **AI document pipelines:** classification, extraction and translation of financial documents with Azure AI Document Intelligence
- **NestJS:** TypeScript backends with TypeORM and PostgreSQL, BullMQ queues, idempotent workflows and advisory locks for safe background jobs across instances
- **Django (DRF):** REST APIs and client portals; cut request processing from ~3 s to ~400 ms and moved heavy work to django-rq workers
- **FastAPI:** Python services for AI and OCR workloads
- **Cloud:** Azure (App Service, Functions, Blob Storage, Service Bus, Event Grid, Entra ID), Docker, GitHub Actions
